# 小柯機器人 YouTube 下載小圖示（瀏覽器擴充功能）

在 YouTube 頁面右下角常駐一個小柯機器人圖示，點一下就能把目前的影片或整個播放清單
**分派到你指定的下載平台**（這台電腦、NAS、工作電腦……）。

支援 Chrome、Edge、Brave、Opera 等 Chromium 系瀏覽器（Manifest V3）。

## 安裝（開發者模式載入）

1. 先讓後端跑起來（專案根目錄的 `啟動小柯YouTube下載工具.bat`，或 `python server/server.py`）
2. 瀏覽器網址列輸入 `chrome://extensions`（Edge 是 `edge://extensions`）
3. 右上角打開「**開發人員模式**」
4. 按「**載入未封裝項目**」，選擇這個 `extension` 資料夾
5. 到任何一部 YouTube 影片頁，右下角就會出現小柯機器人圖示

## 怎麼用

- **小圖示**只會在影片頁（`/watch`、`/shorts`、`/live`）和播放清單頁出現，其他頁面自動隱藏
- 點圖示打開面板：
  - **分派到哪個平台** — 從你設定的後端清單選一個
  - **下載範圍** — 這部影片／整個播放清單（頁面有 `list=` 時才會出現）
  - **檔案格式** — MP4 影片／MP3 音樂
  - **解析度** — 依該影片實際可用的畫質列出
- 下載中圖示外圈會轉紅色，面板顯示進度、階段與目前第幾部
- 完成後會跳通知，面板也會列出檔案連結，可直接存到這台裝置
- 要逐部勾選播放清單，按面板下方「完整介面」會開啟後端的網頁版

## 設定下載平台

點瀏覽器工具列上的小柯圖示（或面板裡的「平台設定」）：

- 新增平台：填名稱 + 後端網址，例如 `NAS` / `https://你的網域`
- 可「測試連線」確認後端活著、yt-dlp 版本
- 選取的平台就是 YouTube 小圖示預設分派的目標

## 為什麼需要背景服務

YouTube 是 https 網站，頁面內的腳本直接連 `http://127.0.0.1` 會被瀏覽器的混合內容
政策擋掉。所以所有跟後端的連線都交給擴充功能的背景服務（`background.js`）執行，
它不受這個限制。

## 檔案

| 檔案 | 作用 |
| --- | --- |
| `manifest.json` | MV3 設定 |
| `background.js` | 與後端溝通的代理、通知 |
| `content.js` | YouTube 頁面上的常駐小圖示與面板（Shadow DOM，不會被 YouTube 樣式影響） |
| `popup.html` / `popup.js` | 下載平台清單設定 |
| `icons/` | 工具列與商店用圖示 |
